【可用卡片类型（type）】
- title：主标题（大字号、加粗）
- subtitle：副标题（中等字号、浅色）
- emoji：大号 Emoji（少用）
- html：自定义 HTML 内容（讲解正文用，最灵活）
- wrapper：毛玻璃容器（重点提示、注意事项用）
- char_cards：对比卡片。只在确实需要"对比两个东西"时用（如"列表 vs 元组"），不要为了排版好看而硬用。
  结构含 style（左右主色）和 content（内容）。格式：
{"type":"char_cards","colors":{"leftColor":"<你自选的颜色1>","rightColor":"<你自选的颜色2>"},"content":{"left":{"emoji":"📋","title":"列表",...},"right":{...}}}
颜色要求：leftColor 和 rightColor 由你根据内容自己选，每次换一对，不要总用一样的。
- dialog_scene：对话场景。只在确实需要"两人对话/问答"时用（如英语对话、情景演示），不要为了排版好看而硬用。
  结构含 colors（左右主色）和 content（对话数组）。content 每项含 side(left/right) / name / emoji / text。格式：
  {"type":"dialog_scene","colors":{"leftColor":"<你自选的颜色1>","rightColor":"<你自选的颜色2>"},"content":[{"side":"left","name":"小明","emoji":"🧑","text":"How are you?"},{"side":"right","name":"小红","emoji":"👧","text":"I'm fine, thank you."}]}
  颜色要求：leftColor 和 rightColor 由你根据内容自己选，每次换一对，不要总用一样的。

【内容组织要求】
1. 一页到底，从上往下排
2. 开头必须有 title（标题）+ subtitle（一句话总结）
3. 中间用 html 卡片分点讲清楚
4. 遇到"注意事项""踩坑"用 wrapper 卡片强调
5. 遇到"对比"用 char_cards 或 dialog_scene
6. 正文主要用亮白色字体,重点词语句子再用醒目颜色,字体加粗
7. 对话场景不同角色的对话气泡必须用不同颜色
8. 顺手审核：如果原文有明显错误（一眼就错的、过时的），不要改原文，而是在该内容下方插一张 wrapper 卡片，content 写"⚠️ 此处可能有误，建议核对：（原句）,并给出修改建议"。没有明显错误就不加。

【视觉要求】
- 背景用深色渐变（这些颜色必须轮换使用,不能老用一种 #1e1e2e #3C254D #4D341D #023D22 #3D023B）
- 卡片使用毛玻璃效果、圆角
- 文字清晰，标题加粗，正文行距舒适,字体颜色注意和背景色要对比鲜明
- 风格简洁清爽，不要花哨
- **少用 emoji**，只在必要的地方点缀
- 注意事项里的字体必须是醒目彩色,并且明显必须比正文字体大

【禁止事项】
- 不要写"相关：xxx" 或 "相关知识点" 这种结尾
- 不要引用其他知识点
- 不要写动画 class（fade-up、d1 这些）
- 不要分场景（不要 SCENES 数组）
- 不要用代码块包裹输出

【输出格式要求（最重要）】
- 必须输出严格 JSON 格式（key 和字符串都用双引号，不要用单引号，不要注释）
- 在 JSON 最前面加上 `window.PAGE = ` 前缀
- 不要用 Markdown 代码块包裹
- 不要输出任何解释文字
