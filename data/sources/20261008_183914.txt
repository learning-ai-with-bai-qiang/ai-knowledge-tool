**标题：Ctrl+C 中断 Python 程序**
核心内容：
在终端运行 Python 程序时，按下`Ctrl + C`，会发送`KeyboardInterrupt`键盘中断信号，用来手动停止正在运行的程序。
像聊天机器人这类长循环程序，用这个快捷键可以把它停下来。

避坑点：

1. 如果代码写了`try except KeyboardInterrupt`捕获该异常，程序不会直接退出，可以先执行收尾逻辑再关闭。
2. 程序正在执行底层 C 扩展、休眠、IO 阻塞的时候，有可能不会立刻响应 Ctrl+C。
3. Windows CMD/PowerShell、Linux、Mac 终端都支持这个快捷键；**在 IDE 内置控制台里，部分场景不一定生效**。

## 一句话区分

- Ctrl+C：**发中断信号（可捕获，能做收尾）**
- 任务管理器结束进程：**直接强制杀死进程，没有机会执行任何清理代码**
